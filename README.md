# HealthPilot - AI-Powered Symptom Checker & Health Companion

## Project Overview

HealthPilot is an AI-powered health management web application that helps users detect potential health issues early, understand their health status better, and manage their wellness more effectively.

## Features

1. **Symptom Checker** - Input symptom descriptions, get AI analysis with severity-based alerts and department recommendations
2. **BMI Calculator** - Calculate Body Mass Index with personalized health advice
3. **Daily Health Tips** - Covering diet, exercise, sleep, mental health, and more

## Tech Stack

- Backend: Node.js + Express
- Frontend: HTML/CSS/JavaScript (responsive design)
- No database required

## Quick Start

```bash
npm install
npm start
# Open http://localhost:3000
```
